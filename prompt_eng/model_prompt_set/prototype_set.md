在你的generate_model.yaml文件中，prototype的类型主要有以下几种，每种类型代表的含义如下：

1. **point**  
   - 含义：表示几何空间中的点或抽象的单一实体。常用于模型中的节点、原点、均衡点等。

2. **axis**  
   - 含义：表示坐标轴或概念轴，是空间或概念划分的基础线。
   - 特点：需要有明显的方向性

3. **vector**  
   - 含义：表示有方向的量，通常依附于某个轴，描述正向或负向的属性。

4. **quadrant**  
   - 含义：表示由两个轴划分出的象限区域，通常用于二维空间的分类。
   - 特点：区域中元素的显性判定条件等于该模型中轴的数量

5. **node**  
   - 含义：表示网络或图结构中的节点，常用于三角形、网络等结构。

6. **segment**  
   - 含义：表示连接两个点的线段，常用于描述变化路径、半径等。

7. **circle**  
   - 含义：表示圆的边界或圆周，用于描述边界、界限等。

8. **region**  
   - 含义：表示空间中的区域，如圆的内部、外部等。
   - 特点：元素判断条件较为自由

9. **set**  
   - 含义：表示集合，用于集合论相关模型，如Venn图、矩阵的行/列集合。

10. **dimension**  
    - 含义：表示维度，通常是集合的枚举值，用于矩阵的行或列。

11. **cell**  
    - 含义：表示矩阵中的单元格，通常由两个维度的交点定义。

12. **function**  
    - 含义：表示函数关系，常用于描述节点之间的作用、反馈等。

13. **edge**  
    - 含义：表示节点之间的边或连接，常用于图结构、三角形等。

14. **symmetry**  
    - 含义：表示对称关系，常用于描述象限之间的变换。

15. **set_operation**  
    - 含义：表示集合之间的运算，如交集、并集等。

16. **relation**  
    - 含义：表示一般的关系，常用于矩阵、集合等结构的交互。
